# 非公開リポジトリを経由しないと push できない公開リポジトリ。publish-gate.sh が使う。
#
#   <公開リポジトリ> <非公開リポジトリ> <非公開リポジトリ内の置き場> [<レビュー記録の置き場>]
#
# 公開リポジトリへ push するコミットは、どれも中身 (ツリー) が、非公開リポジトリの main の履歴に
# 一度でも現れた <置き場> のツリーと完全に一致していなければならない。
# つまり「先に非公開リポジトリの <置き場> に入れて push し、そのツリーをそのまま公開する」以外の経路を止める。
# <レビュー記録の置き場> を書いたときは、さらにそのツリーの公開前レビューの PASS 記録
# (非公開リポジトリの main にある <レビュー記録の置き場>/<ツリーのハッシュ>.pass) を求める。
noxitro/agent-toolkit noxitro/agent-toolkit-private public
