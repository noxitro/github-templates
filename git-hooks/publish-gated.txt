# 非公開リポジトリを経由しないと push できない公開リポジトリ (<owner>/<repo>、1 行 1 つ)。publish-gate.sh が使う。
#
# どの非公開リポジトリを経由するかは、ここには書かない (公開しているこのリポジトリに非公開リポジトリの名前を置かないため)。
# 手元の ~/.config/nox/publish-gate.txt (NOX_PUBLISH_GATE で変えられる) に 1 行ずつ書く:
#
#   <公開リポジトリ> <非公開リポジトリ> <非公開リポジトリ内の置き場> [<レビュー記録の置き場>]
#
# ここに載せた公開リポジトリは、手元の一覧に経由先が無ければ push を止める
# (経由先を知らない環境、たとえばクラウドのセッションから公開側へ直接 push させないため)。
# 手元の一覧にだけ書いた公開リポジトリも同じく絞られる。
#
# 公開リポジトリへ push するコミットは、どれも中身 (ツリー) が、非公開リポジトリの main の履歴に
# 一度でも現れた <置き場> のツリーと完全に一致していなければならない。
# つまり「先に非公開リポジトリの <置き場> に入れて push し、そのツリーをそのまま公開する」以外の経路を止める。
# <レビュー記録の置き場> を書いたときは、さらにそのツリーの公開前レビューの PASS 記録
# (非公開リポジトリの main にある <レビュー記録の置き場>/<ツリーのハッシュ>.pass) を求める。
